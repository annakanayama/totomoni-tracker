# ととモニ 告知画像置き場

LINE公式・Discord両方から使える恒久URLの画像置き場です。

## 使い方
1. 告知画像をこのフォルダにアップロード（GitHubのWebから drag & drop でOK）
2. ファイル名は `YYYY-MM-DD_イベント名.jpg` （例: `2026-08-19_naikan.jpg` / `2026-08-21_zaikei.jpg`）
3. スプレッドシートの「画像URL」列には下の形式のURLを貼る

```
https://raw.githubusercontent.com/annakanayama/totomoni-tracker/main/images/ファイル名.jpg
```

- Discordに貼ってもプレビュー表示されます
- LINEの配信・自動応答でもそのまま使えます（期限切れなし）
